Saving opens the start times now. Times that already have a booking are never changed.

How it works

  • Start times run from the first start time to the last start time, one every interval.
  • Each start time takes one group. Once a group books it, that time is closed to other clients.
  • A group is on tour for the tour length, so a start that would overlap it is not offered.
  • The daily capacity limits the guests on one date, across all of its start times.
  • Every booking is checked again on the server when it is saved, so two clients cannot take the same time.
