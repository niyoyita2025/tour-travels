Travel assistant

The chat button on the public website. Answers come from the tours, prices, dates and policies already on the site.

How it answers

  • Every answer is built from the database when the question is asked: destinations, tours, prices, durations, open dates and the booking policy.
  • If the website has no information, the assistant says so and points to the contact page. It does not guess.
  • Questions about other people's bookings are refused. Customer details are never read or shown.
  • A language model is optional. {% if key_configured %}The server has an API key, so you can turn the option on.{% else %}The server has no API key, so answers are rule-based until one is set on the server.{% endif %}

The API key is set in the server's environment (ANTHROPIC_API_KEY). It is never shown or stored on this page.
